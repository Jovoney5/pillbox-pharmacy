Logging In

How to access your delivery portal.

->
Access the portal
Open your browser and go to /delivery/login. This is your dedicated portal — it is separate from the customer store and the admin panel.
->
Enter your credentials
Type the username and password that was set up for you by the admin. If you do not have credentials or cannot log in, contact your manager to have your account created or reset.
->
After logging in
You will be taken directly to your delivery dashboard. Your name will appear in the top right corner of the screen confirming you are logged in.
Note: Always log out when you are done by clicking the Logout button in the top right corner. Do not share your login credentials with anyone.
2

Your Dashboard

Understanding what you see when you log in.

->
Order cards
Your dashboard shows a grid of order cards. Each card displays the order ID, customer full name, delivery address, parish, number of items in the order, and the order total in JMD.
->
Order statuses
Each card shows a status badge. Processing means the order is ready and waiting for a driver to claim it. Out for Delivery means a driver has already claimed it. Only delivery-type orders appear here — pickup orders are handled in store.
->
Unclaimed vs claimed
Unclaimed orders show a Claim Order button. Orders claimed by you show a Verify Delivery button. Orders claimed by another driver show an "Assigned to another driver" message — do not attempt to deliver those orders.
->
Refreshing the dashboard
The dashboard does not auto-refresh. If you have been waiting and want to check for new orders, reload the page manually in your browser.
3

Claiming an Order

How to assign an order to yourself before going out.

->
Step 1 — Find an unclaimed order
On your dashboard, locate an order card that shows the Claim Order button. Review the delivery address and parish before claiming to make sure you can reach that location.
->
Step 2 — Click Claim Order
Click the Claim Order button on the card. The order status changes to Out for Delivery and the card now shows a Verify Delivery button. The order is now assigned to you.
->
Step 3 — Note the delivery details
Before leaving, write down or screenshot the customer name, full address, and parish. The customer's confirmation code is blurred until you claim the order — once claimed it will be visible on the card so you know what to expect from the customer.
Important: Only claim an order if you are certain you can complete that delivery. Once claimed, the order is assigned to you and removed from the available pool for other drivers.
4

Verifying a Delivery

How to confirm a delivery was completed after handing over the order.

->
Step 1 — Deliver the order to the customer
Bring the package to the address shown on the order card. Confirm the customer's name before handing anything over.
->
Step 2 — Ask for the confirmation code
Ask the customer for their 6-character confirmation code. This code was shown to them on their order confirmation screen after they placed the order. It looks like PB4821. Do not hand over the order until you have verified the code.
->
Step 3 — Click Verify Delivery
On your dashboard, click the Verify Delivery button on the order card. A verification screen will open showing the order details.
->
Step 4 — Enter the code
Type the 6-character code the customer gave you into the large input box on the verification screen. The code is not case sensitive. Click Verify and Mark Delivered.
->
Step 5 — Confirmation
If the code is correct, a green confirmation screen appears saying "Delivery Confirmed." The order status is updated to Delivered and the admin can see the completed delivery. If the code is wrong, a red error message appears — ask the customer to check their confirmation screen again.
Important: Never mark an order as delivered without getting the correct code from the customer. This protects both the customer and you in case of any dispute.
5

Customer Confirmation Codes

What they are and what to do if there is a problem.

->
What is the code
Every order generates a unique 6-character code that starts with PB followed by 4 digits, for example PB7302. The code is shown to the customer immediately after they complete their order online.
->
What if the customer does not have the code
If the customer says they did not receive or cannot find their code, do not leave the package. Ask them to check their order confirmation screen in their browser history, or contact the pharmacy directly. Do not hand over an order without a verified code.
->
What if the code keeps failing
If you have confirmed the code with the customer and it still shows as incorrect, bring the order back to the pharmacy and report it to your manager. The admin can view the correct code on the Orders page.
Reminder: The code on the order card on your dashboard is the correct code for that order. If what the customer gives you does not match, the verification will fail.
6

Rules & Conduct

Standards expected of all PillBox delivery staff.

->
Accuracy
Always verify the customer name and confirmation code before handing over any order. Delivering to the wrong person or address is a serious error.
->
Professionalism
Represent the PillBox Pharmacy brand at every delivery. Be polite, punctual, and presentable. Any issues with a customer should be reported to your manager, not handled personally.
->
Package integrity
Deliver all orders in the condition they were packed. If packaging is damaged before you leave or during transit, report it to the pharmacy before completing the delivery.
->
System use
Only claim orders you intend to deliver. Mark deliveries as completed promptly using the verification system. Do not attempt to access the admin panel — your account only has delivery portal access.
->
End of shift
At the end of your shift, make sure all your claimed orders are either verified as delivered or returned to the pharmacy with a reason. Log out of the portal before closing your browser.
